# Prueba técnica MHLM — entrega completa

Descargar **PruebaTecnicaMHLM-Completa.zip** y extraerlo completo. Empezar por **LEEME.txt** o **README.md**.

Incluye los tres ejercicios:

1. Perfil de Mauricio Hugo López Martín en PDF, versión editable y referencias.
2. RPA ARCA para Windows x64, versión 1.0.2, con ejecutable y código fuente. Permite ingreso manual o perfiles locales y consulta los servicios de la cuenta activa.
3. Informe de operaciones de importación, planilla original, base SQLite, consultas, código y visor portable para ejecutar SQL propio.

No requiere Python ni Git para usar los programas incluidos. El RPA necesita Internet y descarga Chromium en el primer inicio si falta. El visor SQL funciona sin instalación ni Internet. Los PDF pueden leerse en otros sistemas.

Las credenciales y perfiles no se incluyen en el paquete. CAPTCHA y verificaciones de ARCA se resuelven personalmente. El ejecutable del RPA no está firmado digitalmente.

Se adjunta el SHA-256 del ZIP para verificar integridad. Los archivos automáticos **Source code** de GitHub contienen el repositorio, no la entrega portable completa.
